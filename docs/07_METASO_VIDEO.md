# Direct Metaso MiniMax-H3 video production
Owner-selected transport: local Node.js adapter -> direct HTTP to Metaso, never ComfyUI. Base URL https://metaso.cn/api/minimax; POST /v2/video_generation; GET /v2/query/video_generation/{task_id}; Bearer METASO_API_KEY. Model MiniMax-H3. Public reference: https://github.com/meta-sota/ComfyUI-MiniMaxH3-API/blob/main/README.md (direct API example and endpoint table). Provider page https://metaso.cn/minimax-h3. Verify exact reference content schema, result fields, download URL/expiry, error and status values against current provider docs before implementing live calls. Do not assume MiniMax official endpoints are enabled by Metaso.

agy accepts approved asset IDs and shot prompt from Codex; stages private OSS objects; supplies signed GET URLs only in request memory; uses an approved 5–15 second job at 768P or 2K after verifying mode limits. Never expose tokens in logs. Before POST require phase 2, owner-approved batch, uploads, total cost (output + inputs + OSS), max attempts and exact reference set. Persist submission intent first; on uncertain POST result mark unknown and reconcile manually; do not resubmit blindly. Save task ID immediately, poll boundedly with backoff, resume by task ID, download completed media before expiry to temporary local file, verify MIME/size/ffprobe/hash then atomically move into asset storage. Never forward Metaso bearer to a third-party download host. No automatic provider fallback or paid retries. No live adapter is shipped; implement and mock-test before a separately approved pilot.
