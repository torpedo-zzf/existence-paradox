# Authoritative production baseline v0.3.0

This is the complete initialization baseline, not a completed production system. If older documents appear ambiguous, this routing and AGENTS.md govern; escalate actual contradictions. Human communication Chinese; internal contracts English.

| Area | Accountable agent | Tool / transport | Handoff |
|---|---|---|---|
| Product, architecture, permissions, integration | agy | local Node.js, Git, worktrees | task queue and acceptance evidence |
| Story, creative direction, advanced engineering | Codex | approved CLI worker | script, shot list, reviewed code |
| Core visual assets | Codex | ImageGen | canonical actor/location refs, keyframes |
| Consistency edits | agy | Nano Banana | approved reference variants |
| Supporting images | DeepSeek Harness | local ComfyUI Qwen-Image-2.1 | props, evidence, background assets |
| Voice identity before video | agy (Codex designs) | local OmniVoice | approved voice samples and transcript |
| Reference staging | agy | private Aliyun OSS signed GET | ephemeral image/audio URLs |
| Cinematic native AV | agy (Codex directs) | Metaso MiniMax-H3 direct HTTP, never ComfyUI | downloaded native AV with job evidence |
| Original instrumental BGM | agy (Codex directs) | official Suno MCP, manual import fallback, official REST disabled | approved local score and cue sheet |
| Technical QC and editing | DeepSeek Harness | FFmpeg/ffprobe | media reports, separate music tracks |
| Final creative review | Codex | actual asset inspection | continuity, timbre, lip sync, music review |
| Game integration | agy | HTML + JS/TS deterministic runtime | PC/mobile local playable build |
| Optional runtime NPC | agy | server-side DeepSeek API + local OmniVoice | bounded dialogue, authored fallback |

Only agy dispatches workers; no peer-to-peer dispatch. Workers use isolated write scopes/worktrees. Local heavy model execution starts serially. Canonical asset IDs, version, hash, rights and review evidence cross all models. Video uses approved voice and image refs and native audio; music is separate and must not replace native dialogue. Suno may be delegated to a verified Codex MCP client only with agy/owner authorization. No automatic paid provider fallbacks.

Phase 0 offline audit and tests; Phase 0.5 real worker connectivity/worktree evidence by separate authorization; Phase 1 local placeholder slice; Phase 2 separately authorized media pilots and production (including Suno); Phase 3 optional NPC service. Queue dependencies do not bypass human gates. Live adapters and dispatch scheduler are future tasks, not implemented. No actual media, API calls, or cloud resources are included. Name and story are working proposals; 3–5 minute slice before 15–25 minute episode.
